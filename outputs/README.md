# Outputs Directory

This directory stores the final predictions, budget allocations, diagnostic tools, and visualizations generated by the BigBug modeling and optimization pipelines.

## Files Structure

### Submissions & Results
* **`bigbug_predictions.csv`**: The final competition submission containing `Outlet_ID` and forecasted `Maximum_Monthly_Liters`.
* **`bigbug_budget_allocations.csv`**: The final optimized trade marketing budget allocation per outlet for the Western Province.
* **`ensemble_predictions.csv`**: Consolidated predictions generated from the model ensembling process.

### Diagnostics & Visualizations
* **`prediction_diagnostics.csv`**: An expanded diagnostic view of the predictions integrated with context features for analysis and model interpretability.
* **`budget_diagnostics.csv`**: Detailed calculations for the budget optimization process (ranks, tiers, expected uplift, and allocation amounts).
* **`roi_distribution.png`**: ROI score distribution and budget allocation tier boundary visualization.

### Logs & System
* **`pipeline.log`**: Global execution logs for the data preparation, modeling, and optimization steps.

> [!NOTE]
> The binary/analytical output `budget_features.parquet` is stored in the structural data workspace under `data/Optimization/budget_features.parquet` to keep the outputs directory clean.

## Backup & Archive Directories

The following subdirectories contain static backups of historical runs and submissions. These directories **are not** rewritten when the pipeline runs:

* **`round1/`**: Archive of Round 1 predictions and configurations.
* **`round2_lite/`**: Lightweight or intermediate Round 2 run backups.
* **`round2_final/`**: Contains the most recent, final Round 2 model backup and predictions.
