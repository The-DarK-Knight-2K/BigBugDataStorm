# Outputs Directory

This directory stores the final predictions and diagnostic logs generated by the modeling pipeline.

## Files
- `bigbug_predictions.csv`: The final competition submission format containing `Outlet_ID` and `Maximum_Monthly_Liters`.
- `prediction_diagnostics.csv`: Expanded diagnostic view of the predictions with context features for analysis.
- `bigbug_budget_allocations.csv`: The final trade marketing budget allocation per outlet.
- `pipeline.log`: Global logging output for the data processing pipeline.
