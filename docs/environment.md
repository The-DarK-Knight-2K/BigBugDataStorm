# Environment and Dependencies

This document tracks the versions of the programming languages, package managers, and libraries used to build the data pipeline and machine learning models for the Data Storm 7.0 hackathon.

## Core Environment
* **Python**: 3.14.0
* **Pip**: 25.2

## Libraries & Frameworks
* **pandas**: 3.0.3 (Data manipulation and analysis)
* **numpy**: 2.4.5 (Numerical computing)
* **pyarrow**: 24.0.0 (Parquet file engine)
* **scipy**: 1.17.1 (Scientific and statistical computing)
* **pyyaml**: 6.0.3 (YAML configuration parsing)
